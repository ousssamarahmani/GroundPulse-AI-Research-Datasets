# Limitations

- No dataset release exists yet; all data directories are intentionally empty except for status README files.
- Public-source adapters have not been executed for this release.
- No ground-station logs or externally generated synthetic telemetry have been supplied.
- The schemas are proposed normalization contracts and do not prove that matching source fields exist.
- SatNOGS, CelesTrak, and NOAA cover different domains and cannot be joined without explicit identifiers, time alignment, provenance, and missing-data analysis.
- The repository provides no orbit propagation, RF link budget, equipment model, anomaly model, real-time service, operational integration, or mission assurance.
- Any future analysis is research-only and cannot replace qualified mission operators.
