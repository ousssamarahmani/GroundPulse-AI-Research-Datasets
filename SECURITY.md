# Security Policy

This repository contains synthetic research data and no operational integration.

- Never commit ground-station credentials, cloud secrets, private endpoints, command procedures, encryption material, or real telemetry without explicit authorization and a separate approved process.
- Treat any unexpected real operational data as sensitive: stop processing it and contact the repository maintainer privately.
- Report vulnerabilities privately through the repository host's security-advisory mechanism. A publication contact has not yet been configured.
- Public issues are appropriate for non-sensitive data-quality and reproducibility defects.
